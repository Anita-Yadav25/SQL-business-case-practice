# SQL Learning Journey – E-commerce Dataset Practice

This repository contains my SQL practice queries using an e-commerce dataset.

As an aspiring Data Analyst, I’m focusing not only on writing SQL queries but also on understanding the business problems behind the data.

## What I Practiced

### Customer Analytics

* Total registered customers vs customers who placed orders
* Customers with exactly one order
* Customer conversion analysis
* Customer behavior insights

### Order Analytics

* Weekend vs weekday order analysis
* Order trends and filtering
* Business-driven query analysis
